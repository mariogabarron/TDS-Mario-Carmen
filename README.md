**Gestión de Gastos - TDS**

Actualmente, la aplicación permite registrar, modificar y eliminar gastos desde una interfaz gráfica desarrollada con JavaFX y desde una consola interactiva. Incluye categorías predefinidas y la posibilidad de crear nuevas, consulta de gastos en tabla y gráficos de barras y circulares que muestran el importe acumulado por categoría. Ambas interfaces comparten la lógica de gestión. Por ahora, los datos se mantienen en memoria durante cada ejecución; la persistencia está pendiente de implementación.
