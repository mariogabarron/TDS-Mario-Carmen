**Gestión de Gastos - TDS**

Proyecto de la asignatura Tecnologías de Desarrollo de Software (TDS) de la Universidad de Murcia, cuyo objetivo es desarrollar una aplicación de escritorio para gestionar gastos personales. Actualmente, el proyecto se encuentra en su fase inicial, con el repositorio Git configurado, la estructura Maven creada y JavaFX integrado. Se ha implementado y probado una primera ventana funcional con un botón de ejemplo. El desarrollo se realiza en Java, utilizando Eclipse como entorno de desarrollo.
